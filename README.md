## 200M 峰值、3M 固定、5M 独享，是三种东西

宣传页上的带宽数字不能直接横向比。

**峰值带宽**：阿里云轻量的 200M 属于这一类。实测瞬时能接近 200M，但长时间持续大流量会被平台调度限流，套餐内公网流量不限、不产生超额扣费。适合访问量波动的站点，不适合 24 小时跑满。

**固定带宽 + 月流量包**：腾讯云多数轻量是这个模式，比如 2 核 2G 配 4M 固定带宽和 300G 月流量，带宽下限稳定，流量超了按量计费，单价不便宜。跑采集、做下载站、放视频很容易超。

**独享带宽**：京东云和芯飞云标注的 5M、10M 通常指这类。芯飞云 4 核 8G 配 10M 独享、含公网 IP、无流量上限，约 656 元/年，价格明显低于大厂同规格，但节点只限天津，机房单一，没有第二选择。

1Mbps 约等于 128KB/s，这个换算记一下。国内面向公众访问的站点，3Mbps 是能用的下限，低于这个数打开一个带图片的页面要等好几秒。同价位里，雨云 KVM 中配给的 200M 上下行 + 1024GB 月流量，是小厂用带宽换市场的典型做法，代价是机房规模和稳定性不如大厂。

## 轻量应用服务器和标准云服务器，差的不是 CPU

同配置下，标准云服务器（CVM/ECS）的价格通常是轻量应用服务器的 2 到 3 倍。多出来的钱买的是这些：

轻量是打包套餐，限制包括月流量包上限、共享 CPU、网络功能被裁剪、不支持复杂 VPC 组网、一般只能包年包月。标准实例有完整的 VPC、安全组、弹性公网 IP、弹性网卡、负载均衡、备份，能挂载独立数据盘，支持按量付费。

判断线很清楚：装个 WordPress、跑个 API、做开发测试、开游戏服，轻量够用；要同时跑 Web、数据库、缓存，要做多机内网隔离，要按流量弹性扩容，要配负载均衡，就得上 CVM/ECS。腾讯云官方的选型口径也是这么分的：中小企业或大型企业、需要高可用高并发（电商秒杀、实时聊天）、复杂网络架构、精细化资源管理、有专门运维团队，都指向 CVM。

两条容易忽略的计费规则：ECS 释放实例时如果没有手动删除数据盘，数据盘会继续计费；快照长期大量保存会产生额外存储费用。这两项不会在购买页上提醒你。

## 购买前常问的几个问题

**首年 38 元，第二年到底交多少？**
原价 459 元/年，常规折扣打到 8 折也要三百多元。第二年不想付这个价，就在到期前迁到 99 元 ECS 或其他方案。

**轻量应用服务器能升级成标准云服务器吗？**
不能，这是两类产品，配置和网络模型都不同。只能新建一台 ECS/CVM，把数据迁移过去。

**流量超了怎么算？**
阿里云 38 元轻量不限公网流量，不产生超额扣费；99 元、199 元 ECS 是固定带宽计费，公网流量也不额外收。腾讯云多数轻量是固定带宽加月流量包，超额按量计费，跑采集和下载要盯住。

**新客资格怎么判定？**
账号只要买过云服务器就失去资格，买过再退款一样算非新用户。一个人基本只能薅一次。

**实例删了还在扣费是怎么回事？**
ECS 释放时如果没手动删数据盘，数据盘继续计费；长期保存大量快照也会产生存储费。销毁实例时顺手清理这两项。
